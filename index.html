What the scores and price zones mean

Only a company meeting both quality gates and a conservative illustrative entry-price scenario can be labelled ENTRY CANDIDATE. Scenario earnings growth and P/E multiples are assumptions, NOT analyst consensus targets or proven fair values. Review the latest filing and execution price before considering a purchase. Rules assign points for trailing profits, sales growth, valuation ratios and price context. A high score is NOT a probability of profit or intrinsic value. 'Investigate' means review the evidence, not buy a share. Returns in the paper log exclude brokerage, spreads, tax, foreign exchange and dividends.

Why not scan every listed company?

The free feed supplies one quote per API call. A wider universe costs scan time and does not automatically provide reliable fundamentals or up-to-date issuer disclosures. We track a diversified curated sample, deep-screen a rotating batch and display gaps honestly. A sharp move on its own is not an investment thesis.

How this works

GitHub Actions checks publicly accessible sources on a schedule and writes a JSON snapshot. This site reads only that snapshot. Optional API keys stay in GitHub Secrets, never in the website.

Scout uses a transparent rules-based screen plus an optional weekly, out-of-sample-tested machine-learning ranking. The model starts DISABLED and may remain disabled if it fails validation. Your separately scheduled ChatGPT research provides the AI review and notification layer; its messages are not embedded here. For urgent issuer-sourced catalysts the workflow can open an issue in this public GitHub repository. To receive GitHub notifications, watch the repository with All Activity.

This free system is a research tool — not a trading platform, investment adviser or reliable real-time price-alert service.
